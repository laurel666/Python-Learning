# Variables

## Что такое переменная

Переменная в Python — это имя, которое ссылается на объект в памяти.
Когда мы пишем:

```python
name = "Alice"
```

мы не "кладём строку в коробку", а создаём ссылку `name` на объект `"Alice"`.

Это важно, потому что в Python поведение переменных тесно связано с тем,
изменяем ли объект, на который они ссылаются.

## Базовые типы, с которых мы стартуем

На этом этапе нам особенно важны:

- `int` — целые числа
- `float` — числа с плавающей точкой
- `str` — строки
- `bool` — логические значения `True` и `False`
- `None` — специальное значение "ничего" / "отсутствует"

Пример:

```python
age = 28
temperature = 21.5
city = "Moscow"
is_online = True
middle_name = None
```

## Правила именования

Используй `snake_case`:

```python
user_name = "Alex"
order_total = 1499.90
```

Избегай таких имён:

```python
l = 10
O = 5
data1 = "..."
```

Почему это плохо:

- трудно читать;
- легко перепутать `l`, `I`, `1`, `O`, `0`;
- имя не объясняет смысл данных.

## Присваивание и повторное присваивание

```python
counter = 1
counter = counter + 1
```

После второй строки в `counter` будет `2`.

Есть и сокращённая запись:

```python
counter += 1
price *= 1.2
```

## Несколько переменных сразу

Python позволяет присваивать значения компактно:

```python
x, y = 10, 20
first_name, last_name = "Ada", "Lovelace"
```

Это особенно удобно для распаковки и обмена значениями:

```python
left, right = right, left
```

## Приведение типов

Очень часто данные приходят в виде строк, и их нужно преобразовать:

```python
price = "199"
quantity = "3"

total = int(price) * int(quantity)
print(total)
```

Если нужно число с дробной частью:

```python
weight = float("72.5")
```

## Форматирование строк

Самый удобный способ — `f-string`:

```python
name = "Nina"
score = 95

message = f"Студент: {name}, балл: {score}"
print(message)
```

Можно форматировать и числа:

```python
amount = 1532.5
print(f"{amount:.2f}")
```

Это выведет:

```python
1532.50
```

## Полезные операции со строками

```python
first_name = "  alex  "
clean_name = first_name.strip().title()
email = "USER@MAIL.COM".lower()
```

Часто уже на уровне переменных нам нужно:

- убрать лишние пробелы;
- привести регистр;
- собрать итоговую строку из нескольких значений.

## Примеры

### Пример 1. Стоимость заказа

```python
item_price = 249.90
quantity = 3
delivery_price = 199

subtotal = item_price * quantity
total = subtotal + delivery_price

print(f"Итого: {total:.2f}")
```

### Пример 2. Карточка пользователя

```python
first_name = "anna"
last_name = "ivanova"
birth_year = 2000
current_year = 2026

full_name = f"{first_name.strip().title()} {last_name.strip().title()}"
age = current_year - birth_year

print(f"{full_name}, {age} лет")
```

### Пример 3. Распаковка ответа

```python
user_id, user_name, is_active = 101, "Max", True
summary = f"id={user_id}, user={user_name}, active={is_active}"
```

## Типичные ошибки

### 1. Забыть про тип после `input()`

```python
age = input("Возраст: ")
next_year = age + 1
```

Это приведёт к ошибке, потому что `input()` всегда возвращает `str`.

Правильно:

```python
age = int(input("Возраст: "))
next_year = age + 1
```

### 2. Путать `=` и `==`

```python
status = "ok"   # присваивание
```

`=` присваивает значение.  
`==` сравнивает значения.

### 3. Использовать непонятные имена

```python
a = 1200
b = 0.2
c = a * b
```

Такой код работает, но его тяжело читать.

Лучше:

```python
salary = 1200
tax_rate = 0.2
tax_amount = salary * tax_rate
```

### 4. Не учитывать точность `float`

```python
result = 0.1 + 0.2
print(result)
```

Можно увидеть не ровно `0.3`, а число вроде `0.30000000000000004`.

Для финансовых расчётов позже мы отдельно разберём `Decimal`.

## Важные нюансы

### 1. Mutable vs immutable

`int`, `float`, `str`, `tuple`, `bool` — неизменяемые типы.  
`list`, `dict`, `set` — изменяемые.

Пример:

```python
name = "Alex"
name = name.upper()
```

Здесь строка не меняется "на месте" — создаётся новый объект.

А вот список меняется:

```python
items = ["apple", "banana"]
backup = items
items.append("milk")
```

Теперь и `items`, и `backup` смотрят на один и тот же список.

Если нужна копия:

```python
backup = items.copy()
```

### 2. `is` vs `==`

`==` сравнивает значения.  
`is` проверяет, один и тот же это объект или нет.

```python
a = [1, 2]
b = [1, 2]

print(a == b)  # True
print(a is b)  # False
```

Для сравнения значений почти всегда нужен `==`.
`is` обычно применяют для `None`:

```python
if value is None:
    ...
```

### 3. Цепочное присваивание с изменяемыми объектами

Опасный код:

```python
a = b = []
a.append(1)
```

Теперь и `a`, и `b` указывают на один и тот же список.

### 4. `input()` всегда возвращает строку

Даже если пользователь вводит `42`, это всё равно `"42"`,
пока ты сам не преобразуешь значение через `int()` или `float()`.

### 5. Не затеняй встроенные функции

Плохие имена:

```python
list = [1, 2, 3]
str = "hello"
sum = 100
```

Так ты перекрываешь встроенные функции Python.

### 6. Константы — это соглашение

В Python нет "настоящих" констант, но принято писать их в верхнем регистре:

```python
TAX_RATE = 0.2
DEFAULT_TIMEOUT = 30
```

### 7. Pythonic-подход начинается с простых вещей

Уже на уровне переменных полезно:

- давать точные имена;
- преобразовывать данные как можно ближе к месту получения;
- собирать вывод через `f-string`;
- использовать распаковку вместо временных переменных там, где это уместно.

## Что важно уметь после этой темы

После `variables` ты должен уверенно:

- объявлять переменные и переиспользовать их;
- различать базовые типы;
- преобразовывать строки в числа;
- форматировать результат через `f-string`;
- понимать разницу между изменяемыми и неизменяемыми объектами;
- не путать `is` и `==`.
