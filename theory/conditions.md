# Conditions

## Что такое условие

Условие в Python позволяет программе принимать решения.
Идея простая: если некоторое выражение истинно, выполняется один блок кода,
иначе — другой.

Базовый пример:

```python
age = 20

if age >= 18:
    print("Доступ разрешён")
else:
    print("Доступ запрещён")
```

Здесь программа проверяет условие `age >= 18`.
Результат этой проверки — `True` или `False`.

## Операторы сравнения

Чаще всего в условиях используются такие операторы:

- `==` — равно
- `!=` — не равно
- `>` — больше
- `<` — меньше
- `>=` — больше или равно
- `<=` — меньше или равно

Примеры:

```python
temperature = 23
print(temperature > 20)   # True
print(temperature == 18)  # False
```

## Конструкция `if`, `elif`, `else`

### `if`

Если нужен один сценарий при истинном условии:

```python
balance = 1500

if balance > 0:
    print("Баланс положительный")
```

### `if` + `else`

Если есть два варианта:

```python
is_paid = False

if is_paid:
    print("Заказ оплачен")
else:
    print("Ожидаем оплату")
```

### `if` + `elif` + `else`

Если вариантов несколько:

```python
score = 87

if score >= 90:
    print("Отлично")
elif score >= 75:
    print("Хорошо")
elif score >= 60:
    print("Зачёт")
else:
    print("Нужно пересдать")
```

Важно: проверка идёт сверху вниз.  
Как только одно условие сработало, остальные уже не проверяются.

## Логические операторы

### `and`

Оба условия должны быть истинны:

```python
age = 25
has_ticket = True

if age >= 18 and has_ticket:
    print("Можно входить")
```

### `or`

Достаточно, чтобы одно из условий было истинно:

```python
is_admin = False
is_owner = True

if is_admin or is_owner:
    print("Доступ к настройкам есть")
```

### `not`

Инвертирует условие:

```python
is_blocked = False

if not is_blocked:
    print("Пользователь активен")
```

## Булевы значения

В Python логический тип — это `bool`.
У него два значения:

- `True`
- `False`

Многие выражения в условиях возвращают именно их:

```python
price = 500
is_expensive = price > 300
print(is_expensive)  # True
```

## Вложенные условия

Иногда внутри одного условия есть ещё одно:

```python
is_authorized = True
role = "admin"

if is_authorized:
    if role == "admin":
        print("Полный доступ")
    else:
        print("Ограниченный доступ")
```

Так можно, но слишком глубокая вложенность быстро делает код тяжёлым для чтения.
Часто лучше использовать `elif` или объединять условия логическими операторами.

## Проверка строк

Очень часто условия работают со строками:

```python
status = "paid"

if status == "paid":
    print("Отправляем заказ")
```

Если строка приходит от пользователя, её полезно сначала нормализовать:

```python
role = " Admin "
role = role.strip().lower()

if role == "admin":
    print("Права администратора")
```

## Проверка вхождения

Оператор `in` удобен, когда нужно проверить принадлежность:

```python
role = "editor"

if role in ("admin", "editor"):
    print("Можно редактировать")
```

## Практические примеры

### Пример 1. Бесплатная доставка

```python
order_total = 3200

if order_total >= 3000:
    delivery_price = 0
else:
    delivery_price = 299
```

### Пример 2. Проверка доступа

```python
is_verified = True
has_subscription = False

if is_verified and has_subscription:
    print("Контент доступен")
else:
    print("Нужна подписка или верификация")
```

### Пример 3. Статус заявки

```python
score = 72

if score >= 85:
    result = "approved"
elif score >= 70:
    result = "manual review"
else:
    result = "rejected"
```

## Типичные ошибки

### 1. Путать `=` и `==`

Плохо:

```python
if status = "paid":
    print("ok")
```

Такой код вызовет ошибку.  
Для сравнения нужен `==`.

Правильно:

```python
if status == "paid":
    print("ok")
```

### 2. Неправильные отступы

В Python отступы — часть синтаксиса:

```python
age = 18

if age >= 18:
    print("ok")
```

### 3. Неверный порядок условий

Плохо:

```python
score = 95

if score >= 60:
    print("Зачёт")
elif score >= 90:
    print("Отлично")
```

Здесь `score >= 90` никогда не сработает,
потому что значение `95` уже подходит под первое условие `score >= 60`.

### 4. Сравнивать сырые строки без очистки

```python
role = " Admin "

if role == "admin":
    print("ok")
```

Условие не выполнится из-за пробелов и регистра.

### 5. Писать слишком сложные условия без промежуточных переменных

Иногда лучше вынести часть логики в отдельные переменные:

```python
is_adult = age >= 18
has_access = is_adult and has_ticket
```

Так код читается проще.

## Важные нюансы

### 1. Truthy и falsy значения

В условиях Python смотрит не только на `True` и `False`.
Некоторые значения считаются "ложными":

- `0`
- `0.0`
- `""`
- `[]`
- `{}`
- `set()`
- `None`

Пример:

```python
name = ""

if name:
    print("Имя есть")
else:
    print("Имя пустое")
```

### 2. `and` и `or` возвращают не только `True` или `False`

Это важный момент.

```python
user_name = ""
display_name = user_name or "Guest"
```

Если `user_name` пустой, в `display_name` попадёт строка `"Guest"`.

То есть `or` возвращает первый "подходящий" операнд,
а не обязательно булево значение.

### 3. Short-circuit evaluation

Python умеет прекращать проверку раньше времени:

```python
if user is not None and user.is_active:
    ...
```

Если `user is not None` ложно, вторая часть уже не будет вычисляться.
Это защищает от ошибок и делает код эффективнее.

### 4. `is` vs `==`

Для сравнения значений почти всегда нужен `==`.
`is` обычно применяют для `None`:

```python
if value is None:
    print("Нет значения")
```

### 5. Цепочки сравнений

Python умеет так:

```python
age = 25

if 18 <= age < 65:
    print("Рабочий возраст")
```

Это читается лучше, чем:

```python
if age >= 18 and age < 65:
    print("Рабочий возраст")
```

### 6. Приоритет операторов

`not` обрабатывается иначе, чем `and` и `or`,
поэтому в сложных условиях иногда лучше явно ставить скобки:

```python
if is_admin or (is_editor and is_verified):
    ...
```

Скобки часто делают код понятнее.

### 7. Нормализация данных перед сравнением

Если сравниваешь пользовательский ввод, сначала:

- `strip()` — убрать лишние пробелы
- `lower()` — привести к нижнему регистру

Пример:

```python
command = "  YES ".strip().lower()

if command == "yes":
    print("Подтверждено")
```

### 8. Pythonic-подход

Плохо:

```python
if is_active == True:
    print("ok")
```

Лучше:

```python
if is_active:
    print("ok")
```

Плохо:

```python
if is_blocked == False:
    print("ok")
```

Лучше:

```python
if not is_blocked:
    print("ok")
```

## Что важно уметь после этой темы

После `conditions` ты должен уверенно:

- писать `if`, `elif`, `else`;
- сравнивать числа, строки и булевы значения;
- использовать `and`, `or`, `not`;
- понимать порядок проверки условий;
- избегать путаницы между `is` и `==`;
- писать читаемые условия без лишней вложенности.
