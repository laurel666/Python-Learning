# Loops

## Что такое цикл

Цикл нужен, когда одно и то же действие надо повторить несколько раз:

- пройти по списку заказов;
- посчитать сумму продаж;
- найти первый проблемный элемент;
- собрать новый список значений;
- повторять попытки подключения.

Без циклов пришлось бы писать однотипный код много раз вручную.

## Два основных вида циклов

В Python чаще всего используются:

- `for` — когда мы идём по коллекции или диапазону значений;
- `while` — когда мы повторяем действия, пока условие истинно.

## Цикл `for`

`for` используется, когда у нас уже есть набор данных:

```python
sales = [1200, 950, 1430]

for sale in sales:
    print(sale)
```

На каждой итерации переменная `sale` получает очередное значение из списка.

## `for` + аккумулятор

Очень частый паттерн — накапливать результат:

```python
sales = [1200, 950, 1430]
total = 0

for sale in sales:
    total += sale

print(total)
```

Так считают:

- сумму;
- количество;
- среднее;
- объединённые строки;
- найденные элементы.

## Цикл `while`

`while` работает, пока условие остаётся истинным:

```python
attempt = 1

while attempt <= 3:
    print(f"Попытка {attempt}")
    attempt += 1
```

Такой цикл полезен, когда:

- мы повторяем попытки;
- ждём нужного состояния;
- двигаемся, пока не достигнем лимита.

## `range()`

`range()` часто используется вместе с `for`, когда нужен диапазон чисел:

```python
for number in range(5):
    print(number)
```

Это выведет:

```python
0
1
2
3
4
```

Можно задавать начало и конец:

```python
for day in range(1, 6):
    print(day)
```

## `enumerate()`

Когда нужен и индекс, и значение, полезен `enumerate()`:

```python
tickets = ["Login issue", "Payment failed", "Profile bug"]

for index, ticket in enumerate(tickets, start=1):
    print(index, ticket)
```

Это читается лучше, чем ручное ведение счётчика.

## `break` и `continue`

### `break`

Останавливает цикл полностью:

```python
statuses = ["ok", "ok", "error", "ok"]

for status in statuses:
    if status == "error":
        print("Найдена ошибка")
        break
```

### `continue`

Пропускает текущую итерацию и переходит к следующей:

```python
values = [10, None, 15, None, 20]

for value in values:
    if value is None:
        continue
    print(value)
```

## Базовые шаблоны работы с циклами

### 1. Подсчёт суммы

```python
numbers = [5, 10, 15]
total = 0

for number in numbers:
    total += number
```

### 2. Подсчёт количества

```python
statuses = ["done", "todo", "done"]
done_count = 0

for status in statuses:
    if status == "done":
        done_count += 1
```

### 3. Поиск первого подходящего элемента

```python
statuses = ["paid", "paid", "overdue", "paid"]
first_overdue = None

for status in statuses:
    if status == "overdue":
        first_overdue = status
        break
```

### 4. Сбор нового списка

```python
raw_names = ["  anna ", "", " ivan "]
clean_names = []

for name in raw_names:
    name = name.strip().title()
    if not name:
        continue
    clean_names.append(name)
```

## Типичные ошибки

### 1. Забыть изменить счётчик в `while`

Плохо:

```python
attempt = 1

while attempt <= 3:
    print(attempt)
```

Так получится бесконечный цикл.

Правильно:

```python
attempt = 1

while attempt <= 3:
    print(attempt)
    attempt += 1
```

### 2. Ошибка на один шаг в `range()`

```python
for number in range(1, 5):
    print(number)
```

Это выведет `1, 2, 3, 4`, но не `5`.

### 3. Изменять список, по которому идёшь

Так делать опасно:

```python
items = [1, 2, 3]

for item in items:
    if item == 2:
        items.remove(item)
```

Можно получить пропущенные элементы и трудноуловимые ошибки.

### 4. Использовать цикл там, где нужен `break`

Если задача — найти первый подходящий элемент,
часто полезно остановиться сразу после нахождения.

### 5. Писать слишком много логики в теле цикла

Если цикл стал трудно читать, полезно:

- вынести часть условий в отдельные переменные;
- упростить шаги;
- разбить задачу на более понятные этапы.

## Важные нюансы

### 1. Цикл `for` работает через итерацию

Под капотом `for` берёт элементы по одному из итерируемого объекта.
Это важный мостик к будущим темам:

- iterable
- iterator
- generator

Пока достаточно запомнить:
список, строка, кортеж и `range()` уже можно использовать в `for`.

### 2. `range()` не включает правую границу

```python
range(1, 5)
```

даёт:

```python
1, 2, 3, 4
```

### 3. `enumerate()` почти всегда лучше ручного индекса

Плохо:

```python
index = 0

for item in items:
    index += 1
    print(index, item)
```

Лучше:

```python
for index, item in enumerate(items, start=1):
    print(index, item)
```

### 4. `break` и `continue` меняют поток выполнения сильнее, чем кажется

Их полезно использовать, но важно не злоупотреблять.
Слишком много `break` и `continue` в одном цикле делают код труднее для понимания.

### 5. Сложность алгоритмов быстро растёт

Один цикл по списку — обычно `O(n)`.

Вложенные циклы:

```python
for a in items:
    for b in items:
        ...
```

часто уже `O(n^2)`.

Это будет особенно важно позже, когда пойдём в алгоритмы.

### 6. Pythonic-подход

Циклы нужны и важны, но постепенно ты начнёшь замечать встроенные инструменты:

- `sum()`
- `any()`
- `all()`
- list comprehensions

Идея не в том, чтобы "избегать циклов",
а в том, чтобы сначала понимать цикл, а потом выбирать самый читаемый инструмент.

## Что важно уметь после этой темы

После `loops` ты должен уверенно:

- писать `for` и `while`;
- использовать `range()` и `enumerate()`;
- считать сумму и количество через цикл;
- искать элемент с помощью `break`;
- пропускать ненужные значения через `continue`;
- понимать базовую сложность циклов.
