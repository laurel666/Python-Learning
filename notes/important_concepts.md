# Important Concepts

Этот файл будет пополняться по мере прохождения курса.
Сюда будем складывать краткие, но важные наблюдения, которые часто экономят часы отладки.

## 1. Переменная — это ссылка на объект

В Python имя переменной не "хранит значение внутри себя", а ссылается на объект.
Это особенно важно для изменяемых структур данных.

## 2. Mutable vs immutable

- неизменяемые: `int`, `float`, `str`, `tuple`, `bool`
- изменяемые: `list`, `dict`, `set`

Если две переменные ссылаются на один изменяемый объект,
изменение через одну ссылку будет видно через другую.

## 3. `is` и `==` — не одно и то же

- `==` сравнивает значения
- `is` сравнивает идентичность объектов

Практическое правило:

- значения сравниваем через `==`
- `None` проверяем через `is None`

## 4. Не затеняй встроенные имена

Не называй переменные так:

```python
list = [1, 2, 3]
str = "hello"
sum = 10
```

Иначе позже встроенные функции с такими именами перестанут работать ожидаемо.

## 5. Форматирование чисел через `.2f`

Когда видишь запись вида:

```python
f"{value:.2f}"
```

это означает:

- `value` — переменная, которую нужно вставить в строку
- `:` — начало инструкции по форматированию
- `.2f` — показать число как `float` с двумя знаками после точки

Пример:

```python
value = 12
print(f"{value:.2f}")
```

Результат:

```python
12.00
```

Ещё пример:

```python
price = 1899.9
print(f"{price:.2f}")
```

Результат:

```python
1899.90
```

Это особенно полезно для денег, потому что суммы обычно хотят видеть в одном формате:

- `120`
- `120.5`
- `120.567`

после форматирования станут:

- `120.00`
- `120.50`
- `120.57`

Важно:

- `.2f` не меняет само число в переменной, а только форматирует его для вывода
- результат внутри `f-string` становится строкой
