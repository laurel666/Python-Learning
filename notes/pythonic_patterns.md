# Pythonic Patterns

## 1. Давай переменным смысловые имена

Плохо:

```python
a = 1200
b = 0.2
```

Лучше:

```python
salary = 1200
tax_rate = 0.2
```

## 2. Преобразовывай данные ближе к источнику

Плохо тянуть строку `"42"` через половину программы,
если уже известно, что это число.

Лучше преобразовать сразу:

```python
age = int(raw_age)
```

## 3. Используй `f-string` для вывода

```python
message = f"{user_name}: {score}"
```

Это обычно читается проще, чем конкатенация строк.

## 4. Используй распаковку, когда она делает код короче и понятнее

```python
first_name, last_name = "Ada", "Lovelace"
x, y = y, x
```
