# Python Learning Course

Этот репозиторий будет постепенно превращаться в полноценный курс по Python:
от самых базовых тем до алгоритмов, асинхронности и архитектуры проектов.

Как мы работаем:

1. Сначала появляется теория по новой теме.
2. Затем добавляются 10 задач с постепенным ростом сложности.
3. Ты решаешь задачи прямо в файлах из `tasks/`.
4. Я проверяю решения, даю обратную связь и дополняю `reviews/feedback.md`.
5. После этого мы переходим к следующей теме.

Структура репозитория:

- `course/` — общая карта курса и прогресс.
- `theory/` — теоретические материалы по темам.
- `tasks/` — задачи для практики.
- `notes/` — важные концепции и pythonic-подходы.
- `reviews/` — обратная связь по решениям.

Правило работы с задачами:

- не удаляй условие задачи;
- пиши решение ниже docstring;
- если хочешь, можешь коммитить решения после каждой задачи или после блока задач.

Текущая стартовая тема: `variables`.
